# SQL Data Analysis Project

## 📌 Project Overview

This project focuses on analyzing retail business data using SQL Server to identify sales trends, customer behavior, product performance, inventory patterns, returns, promotions, and vendor supply insights.

The project demonstrates practical SQL data analysis skills, including data exploration, data cleaning, joins, aggregations, subqueries, Common Table Expressions (CTEs), window functions, and business-oriented analysis.

---

## 🎯 Business Objective

The main objective of this project is to transform raw retail data into meaningful business insights that can support better decision-making.

Key areas analyzed include:

- Sales performance
- Product performance
- Customer behavior
- Inventory analysis
- Returns analysis
- Promotion performance
- Vendor supply analysis
- Store-level performance
